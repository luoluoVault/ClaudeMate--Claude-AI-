# ClaudeMate
仿Claude极简克制风格AI聊天前端，单文件开箱即用

## 项目介绍
内置**多文件源码版 & 合并单HTML成品**，单文件双击即可运行，无需部署、无需环境配置。
参照Claude界面风格手工轻量化复刻，无冗余功能，专注简洁舒适的聊天体验。

## 核心功能
- 🎨 原生Claude风格界面完整还原
- 🤖 兼容 OpenAI / Anthropic / 所有OpenAI兼容格式API
- 🔄 多API密钥自动轮换
- 📚 角色管理、世界书、知识库配置
- 🌐 联网搜索 & 深度思考模式
- 🧩 Skill插件扩展能力
- 💾 数据导入导出，兼容SillyTavern格式
